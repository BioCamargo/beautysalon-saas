Gatilhos de Envio Automático

Confirmação de Agendamento
Dispara mensagem instantânea quando um horário é agendado no estúdio ou pelo link público.
Lembrete de Véspera / Horário
Envia lembrete para a cliente no dia do atendimento com os dados do profissional e horário.
Recibo ao Fechar Comanda
Envia o comprovante de pagamento detalhado quando a comanda é fechada e recebida no caixa.
Mensagem de Aniversário Automática
Parabeniza suas clientes no dia do aniversário com mensagem carinhosa e cupom de presente.

Como Obter as Credenciais

Meta Cloud API (Oficial):

  1. Acesse developers.facebook.com.
  2. Crie um App do tipo Business e adicione o produto WhatsApp.
  3. Copie o Phone Number ID e gere um Token Permanente em Usuários do Sistema.

Evolution API / Z-API:

  1. Inicie a instância com o nome do seu estúdio.
  2. Copie o endereço da URL e a API Key configurada.
