Como Obter as Credenciais

Meta Cloud API (Oficial):

  1. Acesse developers.facebook.com.
  2. Crie um App do tipo Business e adicione o produto WhatsApp.
  3. Copie o Phone Number ID e gere um Token Permanente em Usuários do Sistema.

Evolution API / Z-API:

  1. Inicie a instância com o nome do seu estúdio.
  2. Copie o endereço da URL e a API Key configurada.
